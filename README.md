# EVOLVE — aplicativo iPhone

Site estático em HTML, JavaScript e CSS, com design responsivo, temas claro/escuro, metas, diário, feedbacks e backup.

## Publicar

Abra **Settings → Pages**, escolha **Deploy from a branch**, branch **main** e **/(root)**, e salve. O endereço será https://opedromoedas.github.io/EVOLVE/.

## Instalar no iPhone

Abra o endereço no Safari → Compartilhar → Adicionar à Tela de Início → Abrir como App.

O app usa localStorage; registros são privados ao dispositivo e não sincronizam. Exporte backups JSON pelo próprio app. **Não publique backups pessoais neste repositório.**
